# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer segments, product performance, discount usage, subscription behavior, and revenue trends.

The project follows an end-to-end data analytics workflow:

**Python → Data Cleaning & EDA → SQL Analysis → Power BI Dashboard**

The goal is to transform raw customer shopping data into meaningful business insights that can support data-driven decision-making.

### 3. Data Cleaning & Transformation

Several preprocessing steps are performed.

#### Handling Missing Values

Missing `Review Rating` values are imputed using the median review rating within the corresponding product category.

```python
df['Review Rating'] = df.groupby('Category')['Review Rating'].transform(
    lambda x: x.fillna(x.median())
)
```

#### Standardizing Column Names

Column names are converted to lowercase and snake_case format for easier analysis and SQL integration.

Example:

```text
Purchase Amount (USD)
        ↓
purchase_amount
```

#### Creating Age Groups

Customers are categorized into four age groups:

* Young Adult
* Adult
* Middle-aged
* Senior

#### Converting Purchase Frequency

Purchase frequency categories are converted into numerical day-based values.

For example:

```text
Weekly → 7 days
Fortnightly → 14 days
Monthly → 30 days
Quarterly → 90 days
Annually → 365 days
```

#### Removing Redundant Data

The `promo_code_used` column is removed because its values are redundant with the `discount_applied` field.

## SQL Analysis

The cleaned dataset is loaded into a SQL database for further analysis.

The SQL analysis covers several business questions, including:

### Revenue Analysis

* Revenue generated by gender
* Revenue contribution by age group
* Total revenue from subscribers vs. non-subscribers

### Customer Analysis

* Customer segmentation into New, Returning, and Loyal customers
* Repeat buyers and their subscription status
* Average customer spending

### Product Analysis

* Top 5 products based on average review rating
* Top 3 most purchased products within each category
* Products with the highest discount usage

### Purchase Analysis

* Average purchase amount by shipping type
* Customers who used discounts while spending at or above the average purchase amount

Example SQL analysis:

```sql
SELECT subscription_status,
       COUNT(customer_id) AS total_customers,
       ROUND(AVG(purchase_amount), 2) AS avg_spend,
       ROUND(SUM(purchase_amount), 2) AS total_revenue
FROM customer
GROUP BY subscription_status;
```

The SQL scripts are available in:

```text
customer_sql.sql
```


### Step 2: Install Python Dependencies


Open:


Run the notebook cells sequentially to:

1. Load the dataset
2. Explore the data
3. Handle missing values
4. Clean and transform the data
5. Create analytical columns

